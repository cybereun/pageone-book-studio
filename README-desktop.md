# PAGEONE · 개인 출판 작업실

한글·워드 원고를 가져와 책 모양으로 편집하고 표지·본문 PDF와 EPUB 전자책을 만드는 Windows 앱입니다. 원고 편집과 조판은 기기에서 처리하며 인터넷은 앱 업데이트 확인·다운로드에 사용합니다.

## 설치와 사용

[최신 Windows 설치 파일](https://github.com/cybereun/pageone-book-studio/releases/latest)에서 PAGEONE-Setup-버전.exe를 내려받아 설치하세요. 기존 책장과 원고를 유지하면서 새 버전을 설치할 수 있습니다.

1. **내 책장**에서 새 책을 만들거나 프로젝트를 엽니다. **원고 가져오기**로 DOCX·HWP·HWPX·IDML·TXT 파일을 가져옵니다.
2. **원고 · 조판**에서 장 제목과 본문을 편집합니다. 왼쪽은 현재 책의 실제 페이지 썸네일이며 클릭하면 해당 미리보기로 이동합니다. **장 목록**으로 전환하면 장을 추가·정렬·삭제할 수 있습니다.
3. **목차 편집** 또는 왼쪽 **목차 넣기 · 편집**에서 목차 제목·항목·순서·포함 여부를 수정합니다. 새 항목은 본문 장을 함께 만듭니다. 목차에서 제외한 장의 본문은 남습니다. PDF 쪽번호는 자동 계산됩니다.
4. **표지 디자인**에서 앞표지·책등·뒤표지·날개를 편집합니다. 제목 크기·색상·이미지·소개글·책등 확정값을 설정합니다.
5. **전자책 미리보기**에서 실제 EPUB을 휴대폰·태블릿 너비로 읽어 봅니다.
6. **출판 파일**에서 종이책 본문 PDF, 표지 전개도 PDF, 전자책 PDF, EPUB 3를 만듭니다.

## 저장과 업데이트

원고는 현재 Windows 사용자 기기의 책장에 자동 저장하며 종료 직전에도 저장합니다. 중복 실행하면 기존 창을 표시해 저장소 충돌을 방지합니다. 저장 실패 시 원고를 남긴 채 종료·업데이트를 멈춥니다. 다른 기기로 옮기거나 별도로 보관하려면 **프로젝트 저장**으로 .pageone 파일을 만드세요. 직접 저장한 파일을 덮어쓰면 직전 파일을 .bak으로 보관합니다.

설치 앱은 시작 후와 실행 중 4시간마다 새 정식 버전을 확인합니다. 새 버전 팝업에서 **업데이트 설치**를 누르면 다운로드하고 현재 원고를 저장한 뒤 설치·재실행합니다. **나중에**를 선택할 수 있으며 하단 **업데이트 확인**으로 직접 확인할 수도 있습니다. 설치 파일의 SHA512를 검증합니다. 업데이트 로그는 %APPDATA%/pageone-personal-studio/update.log에 저장합니다. 2.0.2 이하 앱은 자동 업데이트 기능이 없으므로 기능이 포함된 설치본을 한 번 설치해야 합니다.

## 글꼴과 화면

출판물의 기본 제목·소제목은 **부크크고딕**, 본문·표 내용은 **부크크명조**입니다. 나눔 계열과 D2Coding을 선택할 수 있으며 글꼴을 함께 배포해 오프라인에서도 표시합니다. 앱 조작 글자의 크기와 대비를 높였고 원고 편집 글자는 18px입니다. 제공된 구버전 나눔고딕은 Chromium 호환 문제로 Google Fonts의 수정하지 않은 배포 파일로 대체했습니다. 글꼴 라이선스는 public/fonts의 OFL 문서를 확인하세요.

## 가져오기·출력 지원 범위

| 형식 | 지원 내용 |
| --- | --- |
| DOCX | 본문·강조·표·내장 이미지·주석 |
| HWPX | 본문·강조·표·내장 이미지·주석 |
| HWP 5 | 비암호화 문서 텍스트. 서식·표·이미지는 HWPX로 저장해 가져오세요. |
| IDML | InDesign Story 텍스트와 직접 지정한 일부 서식 |
| INDD | InDesign에서 IDML로 변환한 뒤 가져오기 |
| PDF | 실제 판형·페이지 수 확인, 글꼴 포함, 표지 재단·도련 박스. RGB 출력 |
| EPUB 3 | 탐색 목차·주석 링크·이미지·선택 글꼴, 실제 리더 미리보기 |

복잡한 도형·수식·원본 페이지 배치는 원본과 대조해야 합니다. IDML의 연결 이미지·프레임 배치·상속 스타일은 변환하지 않습니다. PDF는 CMYK/PDF-X 인증 파일이 아니므로 인쇄소 요구 사항을 확인하세요. EPUB 표지는 선택 이미지 또는 간소화한 표지이며 종이책 전개도 전체와 같지 않습니다. EPUB XHTML 언어는 현재 한국어입니다.

## 개발·검증·릴리즈

저장소 루트가 Windows 설치형 소스입니다. Node.js 22 이상과 Windows에서 실행합니다.

```powershell
npm ci
npm test
npm run build
npm run desktop
npm run package:win
```

Google Drive 작업 경로에서 의존성 설치·패키징 문제가 생기면 로컬 NTFS 폴더에 복사해 빌드하세요. 실제 검증 스크립트는 tests/toc-desktop.mjs, thumbnails-desktop.mjs, hwp-browser.mjs, single-instance.mjs, desktop-validation.mjs입니다. PAGEONE_EXE로 설치된 실행 파일을 지정할 수 있으며 검사에는 별도 책장을 사용합니다. 일반 기능 검사에서는 PAGEONE_DISABLE_UPDATES=1로 새 버전 팝업을 끌 수 있습니다.

릴리즈는 GitHub의 **Windows release** 워크플로를 실행하거나 package.json 버전을 올리고 소스를 푸시한 뒤 인증된 gh 환경에서 실행합니다.

```powershell
npm run release:win
```

릴리즈 스크립트는 버전·SHA512를 확인하고 초안 릴리즈에 설치 파일·blockmap·latest.yml을 업로드한 뒤 모두 올라가면 공개합니다. 설치 앱은 최신 정식 릴리즈를 감지합니다. 원고·책장·개인 데이터·인증 토큰은 릴리즈에 포함하지 않습니다.
