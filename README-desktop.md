# PAGEONE 개인 출판 작업실

Windows에서 인터넷 없이 원고를 편집하고, 실제 판형의 책을 미리 보고, 표지·본문 PDF와 EPUB 3를 만드는 앱입니다. 저장소 루트는 최신 Windows 설치형 소스입니다. 기존 README.md는 사용자 요청으로 원문을 보존했습니다. 현재 앱 실행 방법은 이 문서를 참고하세요.

## 실행 및 검증

Node.js 환경에서 저장소 루트에서 npm ci, npm test, npm run build, npm run desktop을 순서대로 실행합니다. Windows 설치 파일은 npm run package:win으로 생성합니다. Google Drive 작업 폴더에서는 의존성 설치와 패키징을 로컬 NTFS 폴더로 복사해 실행하는 것을 권장합니다.

검증 스크립트는 tests/desktop-smoke.mjs, desktop-validation.mjs, dense-validation.mjs입니다. PAGEONE_EXE 환경 변수에 설치된 PAGEONE.exe를 지정하면 실제 설치본을 검증합니다. 검증에는 별도 사용자 데이터 폴더를 사용합니다.

## 지원 범위

- DOCX: 본문·강조·표·내장 이미지·주석. HWPX: 본문·강조·표·내장 이미지·주석. 복잡한 도형·수식과 원본 페이지 배치는 대조가 필요합니다.
- HWP 5: 비암호화 문서의 텍스트. 서식·표·이미지는 HWPX로 저장해 가져오세요.
- InDesign: IDML Story 텍스트와 직접 지정한 일부 서식. INDD는 InDesign에서 IDML로 저장해야 합니다. 연결 이미지·프레임 배치·상속 스타일은 변환하지 않습니다.
- 본문·소제목 글꼴 선택, 실시간 조판, 자동 목차, 책등·날개를 포함한 표지, 프로젝트 파일, 기기 내 자동 저장과 종료 전 저장.
- PDF: 판형·페이지 수 검증, 글꼴 포함, 표지 재단·도련 박스. RGB PDF이며 CMYK/PDF-X 인증 파일은 아닙니다. 인쇄소의 최종 요구 조건을 확인하세요.
- EPUB 3: 목차·주석 링크·이미지와 선택 글꼴 포함, 실제 EPUB 리더 미리보기. 전자책 표지는 현재 간소화된 SVG 또는 선택 이미지이며 종이책 표지 디자인 전체와 같지 않습니다.

## 글꼴

기본 제목·소제목은 부크크고딕, 본문·표 내용은 부크크명조입니다. 제공된 글꼴을 묶었으며 나눔 계열과 D2Coding을 포함한 17가지 글꼴을 선택할 수 있습니다. 제공된 구버전 나눔고딕은 Chromium이 읽지 못해 Google Fonts가 배포하는 수정하지 않은 나눔고딕으로 대체했습니다. Downloads 원본은 변경하지 않았습니다. fonts 폴더의 나눔 OFL 파일을 함께 배포합니다. 글꼴 자체의 소유권은 각 제공자에게 있습니다.

## 보관

내 책장은 이 Windows 사용자 기기에 저장됩니다. 다른 컴퓨터로 옮기거나 중요한 작업을 보관하려면 프로젝트 저장으로 .pageone 파일을 만드세요. 파일을 덮어쓸 때 직전 파일은 .bak으로 보관합니다. 자동 저장에 실패하면 창이 종료되지 않습니다.

## 목차 편집

상단 목차 편집 또는 왼쪽 목차 넣기 · 편집에서 목차 제목·항목·순서·포함 여부를 수정합니다. 목차 항목을 추가하면 본문 장이 함께 만들어집니다. PDF 쪽번호는 자동 계산하며 EPUB 탐색 목차에도 선택 항목이 반영됩니다. 앱 조작 글자와 대비를 키웠고 원고 편집은 18px입니다. 중복 실행 시 기존 창을 표시하여 저장소 충돌을 방지합니다.
