시간은 이 PC의 합성 원고 기준이다. 실제 원고의 그림·표·문단 구성에 따라 달라진다. 300쪽 검사는 작은 장 298개와 앞부분 2쪽이며, 연속 긴 문단은 별도 792쪽 검사로 보완했다.

최종 검토에서 붙여넣기 문단 합쳐짐·여러 원고 각주 ID 충돌·종료 직전 저장 누락·복원 후 미리보기 불일치를 수정했다. 얇은 책(책등 4mm 미만)은 책등 제목을 생략하며 표지 넘침은 내보내기에서 차단한다.

현재 지원 범위와 제한은 README.md에 기록했다. INDD는 IDML 변환이 필요하며 HWP5 직접 가져오기는 텍스트 중심이다. PDF는 RGB이고 PDF-X/CMYK 인증이 아니다. EPUB 표지 디자인은 간소화되어 종이책 표지와 다를 수 있고 XHTML 언어는 한국어로 표시한다.

기존 웹 앱은 수정하지 않았다. 기존 웹 테스트의 서버 렌더링 검사는 루트 dist/server/index.js가 없어 재실행하지 못했으며 새 설치형의 검증과 구분한다.

최종 나눔 글꼴 검증: 선택 가능한 모든 글꼴이 Chromium에서 로딩됨. 나눔명조·나눔고딕 PDF의 포함 글꼴을 확인했고, 해당 EPUB은 EPUBCheck 오류·경고 0으로 통과했다. 나눔고딕 구버전의 빈 TSI3 테이블 문제는 공식 Google Fonts 배포 파일을 사용해 해결했다. 원본 다운로드 파일과 글꼴 이름은 변경하지 않았다.

최종 재설치·재검증 완료: 설치 exit 0, 전체 글꼴 디코딩·기본 및 나눔 PDF/EPUB·프로젝트 저장·재실행 복원·100/300쪽 조판 통과. 전달 설치 파일 SHA256: E81D84828EF1272EC6BF94044776F38574C7A9B328CFBF4F00A7A0873C462189.

## 2.0.1 한글 가져오기 수정과 아이콘

CFB 라이브러리의 브라우저 빌드가 반환하는 일반 배열을 TextDecoder에 바로 전달해 한글 가져오기가 실패했다. 헤더와 본문을 Uint8Array로 정규화했다. 일반 배열로 바꾼 파서 결과에서 회귀 실패를 먼저 재현했고, 수정 후 압축·비압축 HWP 및 암호 파일 거절 검사가 통과했다.

실제 앱에서 압축·비압축 합성 HWP와 실제 HWP 파일의 2254자 본문을 가져온 뒤 10쪽 PDF와 EPUB 출력까지 확인했다. 비어 있는 소개글·출판사 EPUB 메타데이터 오류도 수정했으며 EPUBCheck 오류·경고 0으로 검증했다. 단위 검사 21/21 통과.

사용자 요청으로 투명 배경의 독립 PAGEONE 책 아이콘을 생성했다. PNG 알파 범위 0~255를 확인하고 Windows용 ICO에 16/24/32/48/64/128/256 크기를 포함했다. 설치기·제거기·실행 파일·창·앱 내부 PAGEONE 제목 앞에 같은 아이콘을 적용한다.

추가 회귀 수정: 화면 축소(zoom 0.78)를 조판 전에 적용하면 실제 HWP의 미리보기 7쪽과 출력 PDF 10쪽이 달라졌다. 원래 배율에서 조판한 뒤 표시만 축소하도록 변경했다. 실패 검사를 먼저 재현한 뒤 미리보기·PDF 모두 10쪽으로 일치하는 것을 확인했다.
2.0.1 최종 설치 검증: 설치 exit 0. 설치된 앱의 아이콘·버전 2.0.1·압축/비압축 HWP·실제 HWP·미리보기/PDF 모두 10쪽 일치·EPUBCheck 오류/경고 0 확인. 설치 파일 SHA256: 5FF7F7C0A97C3629F774CE74597F9FE8BCBDC58DE50136E029CCC269458F9091. 기존 앱은 종료 전 저장을 마친 뒤 사용자 데이터 폴더를 로컬 별도 폴더에 복사하고 설치했다.
## 2.0.2 자동 저장 및 목차·가독성 수정

같은 사용자 저장소로 두 앱이 동시에 실행되면 두 번째 IndexedDB 열기가 UnknownError/Internal error로 실패하는 것을 실제 두 프로세스로 재현했다. 단일 인스턴스 잠금을 추가하여 두 번째 실행은 종료하고 기존 창을 표시한다. 저장 거래의 중단·동기 예외에도 연결을 닫고 실패 원인을 표시한다. 저장 성공 뒤 책장 갱신 실패는 저장 실패로 보고하지 않는다.

목차 편집 화면에서 PDF 목차 넣기, 목차 페이지 제목, 장 제목, 새 항목/장 추가, 장 순서, 목차 포함 여부를 편집한다. 제외한 장의 본문은 유지하며 PDF·EPUB 탐색 목차에 선택을 반영한다. 기존 프로젝트는 기본 목차 설정으로 열린다. 앱 조작 글자는 14~16px, 원고 편집은 18px로 확대하고 글자 색 대비를 높였다. 출판물의 부크크 글꼴과 설정은 유지한다.

단위검사 26/26, 실제 앱 목차 편집→PDF/EPUB→재실행 복원, 압축/비압축 및 실제 HWP 가져오기→자동 저장→재실행 본문 동일, 중복 실행 종료/기존 창 복원/후속 저장이 통과했다. 목차 PDF 3쪽에 선택한 항목과 실제 쪽번호 7/9/11이 생성된 것을 PDF 텍스트로 확인했다. 목차 EPUB의 EPUBCheck 오류·경고 0. 현재 작업 중 원고는 사용자가 저장 완료와 앱 종료를 확인한 뒤 사용자 데이터 별도 백업을 만들었다.
2.0.2 최종 설치 검증: 설치 exit 0, 설치된 PAGEONE.exe 및 app.asar가 최종 빌드와 SHA256 일치. 실제 설치본에서 목차 편집·PDF/EPUB 출력·재실행 목차 복원, 압축/비압축 및 실제 HWP 자동 저장·재실행 본문 일치, 중복 실행 차단과 기존 창 복원이 통과했다. 실제 사용자 저장 경로에서도 기존 책 2개를 읽고 자동 저장 성공을 확인했다. 전달 설치 파일 SHA256: 3E50690037E2C1701886D5B7ACFAA10AB016D4E006B0339AB3481A80E35C82AC.

## 페이지 썸네일과 자동 업데이트

2026-10-11: 왼쪽 기본 화면을 현재 책의 실제 조판 페이지 썸네일로 변경했다. 클릭하면 해당 페이지로 이동하고 스크롤 시 현재 페이지를 표시한다. 장 목록으로 전환하면 기존 장 편집을 사용할 수 있으며 목차 넣기 · 편집 버튼을 유지한다. 화면 가까운 썸네일 최대 7개만 렌더링한다. 100/300쪽의 마지막 페이지 이동과 썸네일 제한이 실제 UI 검사에서 통과했으며 이 PC의 합성 원고 기준 1266ms/3792ms였다.

업데이트는 electron-updater 6.8.10을 사용해 공개 릴리즈를 시작 후/4시간 간격으로 확인한다. 자동 다운로드·종료 시 무조건 설치는 끄고 새 버전 팝업에서 설치를 선택하면 다운로드→원고 저장→설치 및 재실행한다. 저장 실패 시 설치를 멈춘다. 단위검사 28/28, 목차·썸네일 실제 UI 검사 통과. Windows release 워크플로와 버전/SHA512 검증 후 초안 릴리즈 업로드→공개 스크립트를 추가했다. 실제 릴리즈 업데이트는 최종 검증 중이다.
최종 2.0.4 실제 업데이트 검증: 공개 릴리즈 v2.0.4에 설치 파일·blockmap·latest.yml 업로드 후 공개 완료. 인증 없이 최신 latest.yml HTTP 200, version 2.0.4 및 SHA512 일치 확인. 설치된 2.0.3을 실행하면 5초 후 새 버전 팝업이 나타났고 업데이트 설치를 선택하니 2.0.4를 다운로드·원고 저장·설치했다. --updated로 실행된 새 프로세스와 ProductVersion 2.0.4.0, 설치 PAGEONE.exe 및 app.asar가 최종 빌드와 SHA256 일치함을 확인했다. NSIS 재실행은 일반 사용자 책장으로 열리므로 테스트 원고는 별도 프로필을 다시 열어 장 제목이 보존됨을 확인했고, 일반 사용자 책장 2개도 설치된 2.0.4에서 읽기·자동 저장 성공을 별도 확인했다. 최신 설치본의 목차/PDF/EPUB/재실행, HWP 자동 저장/재실행, 중복 실행 검증 모두 통과. 설치 파일 SHA256: 17A465D17B0DB153810F1098BEE9429B4A3EA4C8AB35641FB6C376D5CA59FB7F.
