# PAGEONE 구현 기록

2026-10-10: 사용자 승인으로 구현 시작. 브랜치 codex/publishing-studio.

Ruling: 기존 웹 앱을 보존하고 studio 독립 패키지에 설치형을 구현한다. 공통 데이터는 버전 검증하는 JSON과 정제 HTML 장으로 구성한다. 원래 계획의 TypeScript 블록 모델 대신 의미 HTML을 사용하여 DOCX 표·강조·주석과 EPUB 변환을 공유한다. 향후 도형 편집과 정밀 문단 모델은 별도 확장이 필요하다.
Ruling: 사용자 직접 수정 요청에 따라 현재 체크아웃에서 진행한다. 별도 worktree는 만들지 않는다.
Ruling: Google Drive의 의존성 오류를 피하려고 로컬 NTFS에서 빌드·검증하고 산출물을 작업 폴더로 전달한다.

최종 독립 검토: 붙여넣기 DIV 문단 합쳐짐, 반복 원고의 각주 ID 충돌, 종료 직전 저장 누락, 복원 원고와 미리보기 불일치를 발견하여 수정했다. 문단·각주 회귀검사와 실제 즉시 종료·재실행·복원 미리보기 검증이 통과했다. 단위검사 19/19 통과.

Ruling: HWP5는 텍스트, IDML은 Story 중심으로 가져오고 손실 범위를 가져오기 화면에 보고한다. 변환하지 못하는 원본 도형과 배치를 동일하다고 표시하지 않는다.
Final: minor (deferred): EPUB 표지는 간소화된 SVG 또는 선택 이미지로 생성하며 종이책 전개도 디자인 전체를 보존하지 않는다.
Final: minor (deferred): EPUB XHTML 언어 태그는 현재 한국어 기본값이다.

PDF는 RGB이며 PDF-X/CMYK 인증은 이번 설치본 범위에 포함하지 않는다. 계획의 고급 조판·접근성 편집·앱 내부 EPUBCheck·웹 이관 버튼은 다음 단계이며 완료로 표시하지 않는다.

최종 글꼴 검증: Chromium이 나눔고딕의 빈 TSI3 테이블을 거부했다. 회귀 스크립트 font-browser.mjs에서 실패를 재현하고 배포 복사본의 TSI 힌트 소스 테이블을 제거했다. 선택 가능한 모든 글꼴 파일의 실제 Chromium FontFace 로딩이 통과했다. Downloads의 원본과 글자 모양은 변경하지 않았다.
최종 배포 결정: OFL의 Reserved Font Name 조건을 보존하려고 테이블을 제거한 변형본 대신 Google Fonts가 배포하는 수정하지 않은 NanumGothic-Regular/Bold.ttf로 선택 경로를 변경했다. 제공된 구버전 파일은 원본으로 복원했다. 공식 Regular 파일 SHA256 76F45EF4A6BCFF344C837C95A7DCC26E017E38B5846D5AE0CDCB5B86BE2E2D31 일치 확인.
2026-10-11 HWP 수정: CFB 브라우저 빌드의 일반 배열을 Uint8Array로 정규화하여 TextDecoder/DataView 오류를 수정. 압축·비압축 HWP 회귀 검사와 실제 HWP 가져오기→PDF/EPUB 검사 추가. 가져온 원고에서 비어 있는 선택 EPUB 메타데이터를 생략하여 EPUBCheck 오류도 수정. 설치 버전 2.0.1.
사용자 추가 요청: imagegen으로 투명 배경 PAGEONE 책 아이콘을 직접 생성. PNG와 다중 크기 ICO를 프로젝트에 포함하고 Windows 실행 파일·설치/제거기·창·앱 제목 앞에 적용한다. 한글 오류 수정과 같은 2.0.1 설치본에 포함한다.
HWP 화면 검증에서 발견한 zoom 조판 오류도 수정: 조판은 배율 1에서 계산하고 완료 후 미리보기만 축소한다. 실제 HWP 미리보기 7쪽/PDF 10쪽 실패를 재현했고, 수정 후 양쪽 10쪽으로 일치했다.
